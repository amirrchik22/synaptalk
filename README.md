# SynapTalk

Материалы проекта логопедического центра **SynapTalk** (Бишкек, цокольный этаж, 75,14 м²).

## Что внутри

| Раздел | Описание |
|---|---|
| [`brandbook/`](brandbook/) | Бренд-бук: знак, палитра, шрифты, форматы логотипа, планировка, визуализации помещений |
| [`3d/`](3d/) | Интерактивная 3D-модель помещения, геометрия 1:1 по обмерному плану |
| `obmernyi-plan.pdf` | Обмерный план, A2, М 1:50 |
| `planirovki.pdf` | Четыре варианта планировки с разбором |

## Исходные данные

- Внутренний габарит: 6,00 × 13,05 м
- В работе: 75,14 м² (три кабинета, коридор, входной зал)
- Высоты: входной зал 3500 мм, остальные помещения 3000 мм
- Утверждена планировка 04 с групповым кабинетом 15,01 м²

3D-модель собрана на Three.js, работает в браузере без установки.

нужно согласовать со специалистом: несущие конструкции, вентиляция и пожарные
